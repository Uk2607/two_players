📁 Backend Layer Isolation

Models define pure data structures. Repositories manage data access. Services contain all business logic. Events handle network serialization.

🎨 Frontend Single-Page Controller

ScreenManager controls view transitions without full-page reloads. SocketService queues listeners before connection, while ToastService provides glassmorphism notifications.

4. Lifecycle & Resilience: Tab Close vs. Back Button

Solving the challenge of instant offline detection versus remaining available for another game.

sequenceDiagram
    autonumber
    actor PlayerA as Player A
    actor PlayerB as Player B
    participant Browser as Browser Window
    participant Server as Server & Socket.IO
    participant Repo as PlayerRepository

    rect rgb(20, 45, 30)
        Note over PlayerA,PlayerB: Scenario 1: Voluntary Exit ("Back" or "Leave Game")
        PlayerA->>Server: emit('leave_pair')
        Server->>Repo: room_service.leave_pair(sid)
        Note over Server,Repo: Resets both Player A and Player B to "available"
        Server->>PlayerA: emit('left_pair')
        Server->>PlayerB: emit('partner_left', { name: "Player A" })
        Server->>Server: broadcast('player_list')
        Note over PlayerA,PlayerB: Both return to Lobby as Available.
Ready to challenge each other or someone else!
    end

    rect rgb(50, 20, 25)
        Note over PlayerA,PlayerB: Scenario 2: Player A Closes Tab / Navigates Away
        PlayerA->>Browser: Closes Window / Tab
        Browser->>Server: navigator.sendBeacon('/api/leave', { sid })
        Note over Server: Server executes teardown_player_connection(sid)
        Server->>Repo: player_service.unregister(sid)
        Server->>Repo: room_service.cleanup_for_player(sid)
        Server->>PlayerB: emit('partner_disconnected', { name: "Player A" })
        Server->>Server: broadcast('player_list') without Player A
        Note over PlayerB: Player B returns to Lobby as Available.
Player A is completely OFFLINE and removed from list!
    end

📱 1. Scan-to-Join QR Code

The host server prints an ASCII QR code in the terminal and renders a clean QR code on the host's screen. The friend points their phone camera at the screen and joins in 1 second.

import qrcode
qr = qrcode.QRCode()
qr.add_data(f"http://{local_ip}:5050")
qr.print_ascii()

🌐 2. mDNS Local Domain (twoplayers.local)

Supported natively on iOS, Android 12+, macOS, and Windows. Players simply navigate to http://twoplayers.local:5050 without ever asking "what is your IP?".

⚡ 3. Unified Single Server Port

Flask statically serves the frontend/ folder. A single command python app.py hosts both the web app and the real-time game socket on port 5050.

☁️ 4. Cloudflare Quick Tunnel (Remote Play)

Play across different Wi-Fi networks or mobile hotspots without opening router ports:

cloudflared tunnel --url http://localhost:5050

Outputs a free, secure HTTPS URL ready for instant play.

6. Real-Time Protocol & Event Contracts

Complete Socket.IO event dictionary and payload schemas.

Event Name Flow Direction Payload Schema Description
register Client → Server { name: string } Registers player nickname
registered Server → Client { id: string, name: string } Confirms registration and assigned SID
player_list Server → All Array<{ id, name, status }> Broadcasts online players & availability
send_invite Client → Server { target_id: string } Dispatches 1v1 challenge to target player
invite_received Server → Target { from_id, from_name } Displays incoming challenge modal
accept_invite Client → Server { from_id: string } Accepts challenge and forms room
paired Server → Both { room_id, player1, player2 } Initializes paired game selection screen
select_game Client → Server { room_id, game_id } Selects game from the catalog
game_selected Server → Both { game_id, room_id, state } Launches the interactive game arena
leave_pair Client → Server {} Leaves game; resets both to Available
partner_left Server → Partner { name: string } Returns partner to lobby as Available
POST /api/leave Beacon → Server { sid: string } Tab close notification; marks Offline
partner_disconnected Server → Partner { name: string } Notifies partner of tab closure
